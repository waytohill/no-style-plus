This is a demo site for **no-style-plus**, a Jekyll blog template built on [no-style-please](https://github.com/riggraz/no-style-please).

## What you get

- Minimalist black-and-white design
- Dark mode (click the button in the top-right corner)
- Full-text search (press `/` from any page)
- LaTeX math rendering
- Code blocks with a copy button
- Series navigation, related posts, backlinks
- Tags and categories
- Tufte-style sidenotes on wide screens
- GitHub-style callouts (`[!NOTE]`, `[!TIP]`, `[!WARNING]`)
- Mermaid diagrams
- GoatCounter analytics (optional)
- Giscus comments (optional)

## Getting started

1. Fork or use this repo as a template
2. Edit `_config.yml` to set your site title, URL, and author
3. Run `python new_post.py` to create your first post
4. Push to `main` — GitHub Pages deploys automatically
